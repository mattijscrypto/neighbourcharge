Zonder maandabonnement.

Wat zit er in de gratis backoffice?

Bij verhuursessies stelt Pluggo automatisch een self-billing factuur op namens jou. BTW-status (KOR of zakelijk), de juiste tarieven, kWh-onderbouwing — het klopt altijd, zonder dat jij een factuurprogramma hoeft aan te raken.

ERE — energiebelasting terugvorderen

ERE (Energie Reken Eenheid) is een regeling waarmee zakelijke afnemers de energiebelasting terugvorderen die is betaald over kWh die via hun laadpunt aan derden is geleverd. In 2026 gaat het om ca. €0,22 per kWh. Bij 312 kWh aan verhuursessies per maand is dat ruim €68 terug via je energieleverancier — per jaar meer dan €800.

Voorwaarden voor een geldige ERE-aanvraag:

  • Je bent zakelijk afnemer (niet KOR-particulier) of werkt via een erkende ERE-dienst.
  • Je laadpunt heeft een MID-gecertificeerde kWh-meter — dit is het juridisch geldige meetpunt.
  • Je kunt de geleverde kWh per periode aantonen.

Pluggo registreert automatisch alle kWh die via OCPP binnenkomen. Heb je een MID-meter op je paal, dan activeert Pluggo de ERE-tegel in je dashboard en houdt het systeem je maandtotalen bij. Je hoeft niets handmatig bij te houden.

Nog geen MID-meter? Veel installateurs kunnen een gecertificeerde submetering toevoegen aan je bestaande installatie. Vraag je installateur naar een MID-gecertificeerde sub­meter — dan is alles meteen klaar voor ERE én voor Pluggo.

Hoe koppel je jouw laadpaal aan Pluggo?

Pluggo werkt met alle laadpalen die OCPP 1.6 JSON of OCPP 2.0.1 ondersteunen. Dat geldt voor de meeste moderne thuislaadpalen.

  1. Download de Pluggo-app — gratis in de App Store of Google Play. Maak een account aan.
  2. Ga naar Mijn paal → Slimme paal koppelen — kies je merk. De wizard geeft je de exacte OCPP-URL die je in jouw paalsoftware invult. Per merk wordt uitgelegd waar die instelling zit.
  3. Vul de URL in je paal in — via de merk-app (myWallbox, Easee app, Alfen Connect) of webinterface. De meeste merken zijn gekoppeld in minder dan 8 minuten.
  4. Paal verschijnt online in de app — je ziet direct de verbindingsstatus. Vanaf nu kun je eigen sessies starten en bijhouden vanuit de app.
  5. Optioneel: paal beschikbaar stellen voor verhuur — stel je prijs en beschikbaarheidsvensters in. Je paal verschijnt op de Pluggo-kaart voor rijders in de buurt.

Veelgestelde vragen

Kost Pluggo iets als ik alleen mijn eigen laadsessies bijhoud?

Nee. Het bijhouden van eigen laadsessies via Pluggo is volledig gratis. Geen maandabonnement, geen starttarief. Alleen bij verhuur aan buren houdt Pluggo een kleine platformfee (€0,03/kWh per kant) in op die sessies.

Kan ik Pluggo gebruiken zonder buren te laten laden?

Ja. Je koppelt je paal eenmalig via OCPP en start eigen sessies via de app. Je ziet het live dashboard, maandtotalen en je kWh-geschiedenis. Je hoeft de paal niet beschikbaar te stellen voor anderen — dat is volledig optioneel.

Hoe werkt de ERE-registratie precies?

Pluggo registreert automatisch alle kWh die via OCPP binnenkomen. In je maandoverzicht zie je het totale ERE-kWh (eigen laden + verhuur bij sessies via een MID-gecertificeerde meter), plus een schatting van de terugvorderbare energiebelasting (ca. €0,22/kWh in 2026). Je dient de ERE-aanvraag in bij je eigen energieleverancier of via een erkende ERE-dienst. Pluggo levert het kWh-overzicht als onderbouwing.

Kan ik Pluggo gebruiken naast een bestaand backoffice-abonnement?

Nee — een OCPP-paal kan maar aan één centrale zijn gekoppeld tegelijk. Je stelt de Pluggo-OCPP-URL in als primaire centrale. Heb je een abonnement bij E-Flux of New Motion? Dat kun je opzeggen zodra Pluggo is gekoppeld. Voor palen die via een lease-constructie zijn gebonden aan een specifieke backoffice is overstappen helaas niet mogelijk.

Wat als mijn paal niet OCPP ondersteunt?

Je kunt Pluggo dan nog steeds gebruiken voor verhuur — de boeker start zelf de laadbeurt (vrij-laden modus) en jij voert achteraf handmatig de kWh in. Het live dashboard, eigen sessies en automatische ERE-registratie vereisen echter een OCPP-verbinding. Zie Werkt mijn laadpaal op Pluggo? voor de check per merk.

Hoe verschilt 'eigen sessie' van een verhuursessie in de app?

Een eigen sessie start je zelf via de knop "Start eigen laadsessie" in het Mijn paal-dashboard. De sessie wordt bijgehouden als "eigen laden" en telt mee in je eigenKwh-totaal voor de maand. Een verhuursessie wordt gestart via een boeking van een rijder en telt mee in je verhuurKwh. Allebei tellen mee voor ERE als je paal een MID-meter heeft.
